# ClariGauge

适用于 Apple 芯片和 macOS 15+。双击 `dist/ClariGauge.app` 后，屏幕顶部菜单栏显示最高传感器温度、各风扇 RPM 和已用内存。点击数值可打开对应实时小窗，底部菜单可打开完整面板、勾选电量、内存、磁盘余量和实时上下行。选项会记住。菜单中选择退出可停止采集。

## 已实现

- 电池电量、充电/接电状态；数据卷存储占用与可用空间。
- 系统已用、应用、有线、压缩内存；应用 RSS 排行，可展开查看每个 PID。
- IOHID/SMC 温度及每个风扇实际 RPM，只读、不控制转速。
- 物理 en* 网卡实时上下行和滚动 60 分钟曲线。
- nettop 应用最近一小时上下行排行，Clash/Mihomo 独立卡片。
- 最近一小时活跃 Codex 对话标题与 token 增量，应用共享流量单独显示。

## 统计边界

应用流量与代理流量可能重复，不加总为整机流量。网络从采样开始积累；未运行时没有记录。应用新进程需要基线、连接消失导致计数回退可能少计，因此应用排行是已观测流量下界。物理流量不包含 lo0/utun 等虚拟接口；多个物理接口有转发时也可能重复。

RSS 包含共享页，与系统内存总量不是可加总关系。存储是用户主目录所在数据卷的文件系统口径，不是每个目录的扫描结果。

Codex **对话级网络字节尚未实现**。共享进程与连接不能可靠映射到对话，不以 token 估算字节。token 来自本地日志累计计数增量；首次基线、日志尾部 4 MiB 限制、上下文压缩重置可能少计。仅查询数据库元信息和解析 token_count 记录，不保存正文或凭据。

数据仅保存在 `~/Library/Application Support/MacPulse/`，无 HTTP 服务、无上传、无登录自启。0.5.0 起采集器使用应用内置 Python 运行时；传感器私有接口将随系统变化，缺失显示不可用。原生应用在普通用户会话下读取指标；受限终端可能无法调用 nettop/ps/传感器。

## 构建与验证

```sh
./build.sh
python3 -m unittest discover -s tests -v
```

应用流量每 15 秒汇总，每分钟保存历史。统计最多回看 60 分钟，窗口边缘最多提前 15 秒丢弃最旧桶。运行目录覆盖写入历史和最新快照，每份最多 4 MiB；历史达到容量限制时优先保留最新记录。启动时清理遗留临时文件和超过 24 小时的缓存。应用退出后暂停采集和清理，下次启动时执行过期检查。

从 0.3.0 起，每个顶部指标都可独立点击，下拉小窗直接查看实时详情，悬停显示操作提示。温度包括 CPU/GPU 温区汇总、分项温度与系统热状态，内存包含系统分类与应用 RSS，网络包含实时速率、曲线及最近一小时应用流量。风扇窗口可打开本机已安装的 Macs Fan Control 进行调节。

0.4.0 的流量页面支持最近 5/15/30/60 分钟及自定义 1–60 分钟统计。应用上下行、Clash 用量和曲线同步切换，显示区间起止与实际网卡采样覆盖。区间为随实时数据向前滚动的时长，应用按 15 秒桶汇总，窗口边缘可能少计最多 15 秒。

0.5.0 将独立 CPython 3.12 运行时和采集器所需标准库打入应用。启动使用内部相对路径，并忽略外部 Python 环境和用户包，关闭字节码缓存。系统采集接口仍使用 macOS 自带 ps/nettop/ifconfig 等工具和系统框架。Macs Fan Control 为可选的外部调速入口。构建时先用 scripts/bundle_runtime.py SOURCE .local/python-runtime 准备独立运行时，之后执行 build.sh。来源与校验清单位于包内 python/RUNTIME.json，许可证保留在标准库 LICENSE.txt。
