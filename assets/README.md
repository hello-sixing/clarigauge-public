# Mac Pulse 图标

- 最终文件为 AppIcon-v1.png，带透明背景。
- 使用内置 image_gen 工具，由已选中的深蓝/薄荷绿脉搏图标去除外部灰底生成。
- build.sh 使用 sips 生成标准尺寸，再使用 iconutil 打包为应用中的 AppIcon.icns。

最终编辑提示词如下。

> Prepare this exact approved Mac Pulse app icon for installation. Preserve the entire dark navy rounded-square tile, mint cyan pulse ribbon, lighting, proportions, bevels and all details exactly. Remove ONLY the light gray background outside the rounded square and make those outside pixels fully transparent. Keep the full square canvas and existing equal margins. The rounded square and all artwork inside it must remain opaque. No gray or white outside backdrop, no new elements, no text, no redesign. Return a clean transparent PNG cutout ready for a macOS .icns file.
